# gatecell

Gate validation gates for cell inputs before they hit prod.

**Site:** https://theworker02.github.io/gatecell/

## Install / run

```bash
git clone https://github.com/theworker02/gatecell.git
cd gatecell
node src/cli.js
node --test
```
